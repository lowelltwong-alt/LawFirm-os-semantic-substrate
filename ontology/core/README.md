# Stable Core Ontology

This directory is reserved for stable, domain-neutral semantic primitives.

## Intended core classes

- Capability
- Entity
- State
- Constraint
- Evidence
- Assessment
- Profile

## Rule

Objects in this layer should change slowly and should not be directly mutated by raw runtime learning events.

## Next implementation targets

- canonical Turtle files for classes and properties
- JSON-LD context for stable identifiers
- namespace policy and version policy
