# System Map

## What this repository is

Law Firm is a semantic-governance substrate and Innovation OS contract repository.

It brings together:
- canonical ontology and taxonomy artifacts
- governed runtime learning objects
- canonical document structure plus derived document and evidence artifacts
- retrieval and access contracts
- vendor profiles and mappings
- evaluation and operating-model governance

## Major folders

- `ontology/`  -  canonical semantic modules
- `shapes/`  -  SHACL validation layers
- `schemas/`  -  JSON contracts for runtime, document, retrieval, and view objects
- `examples/`  -  validating example objects and thin slices
- `profiles/`  -  vendor and system adapter profiles
- `mappings/`  -  explicit source-to-canonical mappings
- `governance/`  -  doctrine, lifecycle, operating model, and release guidance
- `registry/`  -  authoritative registries for source-of-truth and modules
- `standards/`  -  stable policies for identifiers, taxonomy, security, quality, and telemetry

## How the parts fit together

1. Ontology and taxonomy define stable meaning.
2. Shapes and schemas define machine-checkable contracts.
3. Runtime learning objects capture exceptions, pressure, opportunity, validation, and promotion.
4. Canonical document objects preserve traceable source structure and source-of-truth boundaries.
5. Derived evidence and retrieval contracts consume that canon without redefining it.
6. View contracts turn one normalized object set into multiple user-facing outputs.
7. Governance and cadence files define how change is approved, measured, and scaled.
