# Implementation Order

## Required sequence

1. Document selection and cleanup
2. Taxonomy and metadata design
3. Governance and access control
4. Canonical document structuring and chunk policy
5. Embeddings and indexes
6. Retrieval, RAG, GraphRAG, and AI interfaces

## Rule

Do not start with embeddings, vector databases, or GraphRAG before canonical structure, metadata, governance, and evidence contracts exist.

## Build discipline

- Canonical semantics first
- Runtime learning second
- Retrieval contracts third
- Vendor profiles after the contracts exist
- Optimization last
