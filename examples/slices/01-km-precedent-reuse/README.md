# Slice 01 — KM Precedent Reuse

## Goal

Show how an approved precedent or work-product asset is represented in the canonical model, retrieved through a governed path, and surfaced as an evidence-backed reuse artifact.

## Flow

1. Canonical document and document version exist.
2. Relevant components and spans are preserved.
3. Retrieval request references canonical identifiers and access context.
4. Evidence bundle is generated from stable span references.
5. Reuse remains attributable and reviewable.

## Success condition

A reviewer can trace the reuse output back to exact canonical source spans and approval context.
