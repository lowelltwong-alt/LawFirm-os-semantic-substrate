# AI Front Door Suggested Questions

Use these questions to orient any human or AI assistant.

## Basic orientation

- What is this repository?
- What is the difference between this repo and a runtime system?
- What are the most important files to read first?
- What is the authority order when docs conflict?
- What does this repo currently guarantee?
- What does it not claim yet?

## Governance and validation

- Which validation commands should I run?
- What does `bash scripts/run_full_audit.sh` currently do?
- Why does SHACL fail closed?
- What does it mean that SHACL conformance is not currently claimed?
- Which files define the source of truth?
- Which docs are historical or non-authoritative?

## Exceptions Lake

- What is the Exceptions Lake boundary?
- What belongs in this repo versus a future runtime lake?
- How does an exception become a learning signal?
- What is the path from exception-event to promotion-decision?
- Why can raw exceptions not mutate canon directly?

## Automation manager questions

- How do I evaluate an automation candidate?
- What is the intake form for an automation idea?
- What validation gates are required before scaling?
- How do I turn a recurring operational issue into an opportunity object?
- What should go into the first sprint?

## CINO questions

- What is the strategic value of this repo?
- How does it reduce hallucination risk?
- How does it support Innovation OS governance?
- What decisions are needed before internal corpus ingestion?
- What are the next 30/60/90-day actions?
