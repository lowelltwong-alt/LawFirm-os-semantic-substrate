# Demo Pitch

## 30-Second Version

We built a bounded semantic governance pilot for intake, conflicts, and AI use. It turns policy logic, restrictions, and provenance into a machine-readable decision substrate so answers can be more consistent, more explainable, and safer to use as we prepare for knowledge-management and AI enablement.

## 2-Minute Version

The problem is that important policy decisions often live across documents, people, and workflow memory. That makes answers inconsistent, hard to explain, and difficult to scale into AI safely.

This pilot creates a governed semantic layer for one high-value workflow: intake, conflicts, and AI use. It keeps substrate-native operating semantics at the center, uses established standards where they help, and preserves provenance, access boundaries, and reviewability.

What makes this useful now is that it can answer bounded questions like:
- Can AI be used here?
- What governs the answer?
- What restriction changes it?
- What would require approval to change it?

What makes it strategically valuable later is that the same pattern can support broader KM and AI architecture without losing governance, trust, or explainability.
