# Supported Questions

This pilot is designed to support a bounded set of operationally meaningful questions.

## Core Questions

- Can AI be used here?
- What governs this answer?
- What restriction changes this answer?
- What source supports this answer?
- What would need approval to change this answer?

## Pilot-Framed Examples

### 1. AI use on intake material
Can generative AI be used for first-pass intake summarization on this matter?

### 2. Governing basis
Is the answer controlled by a firm baseline, a client restriction, a matter-specific condition, or an exception path?

### 3. Restriction discovery
What policy or governance restriction makes this answer narrower than the baseline?

### 4. Support traceability
Which semantic artifacts, manifests, feedback records, or reviewable objects support the answer?

### 5. Change path
If the current answer is too restrictive for the workflow, what would have to be reviewed or promoted to change it?

## What These Questions Demonstrate In A Bounded POC

These questions show the kinds of bounded capability the pilot is intended to demonstrate as:
- a governed policy-intelligence layer
- a provenance-aware retrieval substrate
- a future AI-support foundation
- a reusable KM and governance pattern

## Important Constraint

This pilot does not claim to provide enterprise-wide policy automation.
It demonstrates that a bounded workflow can be represented in a governed, machine-readable way that supports clearer review and future scaling.
