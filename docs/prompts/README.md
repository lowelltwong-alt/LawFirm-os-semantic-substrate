# Prompt Kit

Reusable handoff prompts for repository ingestion, alignment cleanup, and role-based review.

## Files

- `AZURE_AI_ARCHITECT_PROMPTS.md`: practical prompt set for an Azure AI architect taking over the platform and implementation side.
- `CODEX_ALIGNMENT_MASTER_PROMPT.md`: full cleanup/alignment instruction set for coding agents.
- `KNOWLEDGE_MANAGER_PROMPTS.md`: practical prompt set for a KM lead taking over stewardship, adoption, and workflow ownership.
- `REPO_INGEST_AND_ALIGNMENT_PROMPTS.md`: ingest/extract/alignment prompt variants.
- `PERSONA_PROMPTS.md`: role-specific reviewer prompts (CINO, KM Director, Azure AI architect, ontology engineer, technical executive).

## When to use

Use this directory when handing work across:

- branches
- teams
- AI sessions
- sponsor review cycles

These prompts are reusable orchestration artifacts; they do **not** replace canonical architecture or governance docs.
