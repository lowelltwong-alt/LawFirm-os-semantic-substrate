# Exceptions Lake Contract Consumption Map

## Purpose

This map tells a future runtime implementation which Law Firm contracts it must
consume for each operational need.

The runtime may implement storage, queues, workers, and dashboards elsewhere,
but it must consume the canonical contracts listed here and stay within the
promotion boundary.

- `may influence canon?` means whether the runtime need can ever contribute to a
