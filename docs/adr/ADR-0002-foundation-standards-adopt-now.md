# ADR-0002 Foundation Standards Adopt Now

## Status
Accepted

## Decision

The repository adopts these as foundational support standards:

- RDF / JSON-LD
- SKOS
- PROV-O
- DCTERMS
- SHACL
- OWL-light

## Why

These solve broad semantic problems already present in the repository:
- graph packaging
- controlled vocabularies
- provenance
- metadata
- validation
- light semantic interoperability

## Why Now

They are low-regret, broadly useful, and directly support the current substrate-native architecture.

## Why Not Core

These standards support the model, but they do not define Law Firm operating semantics.
substrate-native objects remain the design authority for policy topics, operating positions, governance baselines, and retrieval packages.

## Review Trigger

Review if one of these standards stops producing clear operational value or starts obscuring substrate-native meaning.
