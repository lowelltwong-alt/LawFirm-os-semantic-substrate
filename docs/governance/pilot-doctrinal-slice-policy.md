# Pilot Doctrinal Slice Policy

Pilot doctrinal slices should be bounded, infrastructure-proving, and narrow
enough to validate the system before broad population.

## Rules

- pilot slices should remain deliberately small
- a slice should identify target thinkers, doctrines, concepts, and comparisons
- competency questions and exit criteria should be explicit
- a slice should declare required artifacts and validation posture

## Non-Goal

This phase does not attempt full doctrinal population. It proves the
infrastructure with a bounded slice.
