# Agent/Skill Capability Graph and Registry

This surface governs a large-scale Agent/Skill Capability Graph and Registry for substrate-neutral descriptions of agents, subagents, skills, monitors, orchestrators, workflows, tags, typed edges, owners, cadence, audit posture, and future derived discovery outputs.

## Purpose

Use this area to keep a potentially very large number of capability surfaces organized without turning generated discovery artifacts into canonical truth.

This surface is a governed-learning input surface for governed recursive improvement, not autonomous self-modification.

## Canonical versus derived

Canonical in this surface:
- registry cards
- controlled tags
- typed canonical edges
- ownership
- cadence
- audit posture

Derived in future adjacent surfaces:
- embeddings
- generated indexes
- candidate duplicate edges
- similarity neighborhoods
- overlap reports
- GraphRAG summaries
- community reports

Derived artifacts may inform review. They may not directly mutate canonical cards, tags, edges, ownership, cadence, or audit policy.

## Governed-learning boundary

Use the existing authority path:

`candidate signal -> assessment -> recommendation -> adaptation-proposal recommendation if reviewed -> promotion-decision only through existing authority path`

## Non-goals

- runtime execution
- scheduler implementation
- `.claude/agents` or `.claude/skills` content
- generated indexes in this PR
- embeddings in this PR
- GraphRAG packages in this PR
- production feed design
- raw transcript capture
- autonomous repo rewriting
