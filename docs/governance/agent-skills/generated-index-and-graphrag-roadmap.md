# Generated Index and GraphRAG Roadmap

This roadmap defines future derived discovery outputs for the Agent/Skill Capability Graph while preserving canonical authority boundaries.

## Canonical versus derived

Canonical:
- registry cards
- controlled tags
- typed canonical edges
- ownership
- cadence
- audit posture

Derived:
- embeddings
- generated indexes
- candidate duplicate edges
- similarity neighborhoods
- GraphRAG summaries
- community reports
- overlap reports

Derived outputs are never canonical truth.

## Roadmap phases

1. docs-only canonical registry model
2. manual card inventory and controlled tags
3. generated flat indexes and adjacency summaries
4. generated overlap reports and orchestrator impact matrices
5. generated embeddings and neighborhood summaries
6. generated GraphRAG discovery digests

## Derived artifact marking

All future derived outputs should be marked with:
- `derived_not_canonical`
- source commit SHA
- source card refs
- generation timestamp

## Boundary

This PR does not add generated indexes, embeddings, overlap reports, or GraphRAG packages. It only defines the governance roadmap for those future derived surfaces.
