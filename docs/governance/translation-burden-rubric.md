# Translation Burden Rubric

Translation burden expresses how much conceptual, historical, institutional, or
terminological translation is required before a comparison judgment can be used
responsibly.

## Categories

- `minimal`
- `low`
- `moderate`
- `high`
- `extreme`

## Purpose

This keeps the comparison layer honest about when two positions appear close
only after significant interpretive translation.

## Rule

Higher translation burden should remain visible even when the eventual
alignment degree is strong.
