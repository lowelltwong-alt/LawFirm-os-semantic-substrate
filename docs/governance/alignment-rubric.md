# Alignment Rubric

This rubric defines how governed comparison assessments should express alignment
without collapsing nuanced interpretation into oversimplified scoring.

## Purpose

The repository already supports relation verbs and alignment labels. This rubric
adds a governed assessment layer that makes comparison judgments more machine-usable.

## Core Rules

- alignment remains context-sensitive
- alignment must name the scope being assessed
- alignment should remain compatible with existing `relation_type` and `alignment_degree`
- assessment objects should remain separate from raw comparison objects

## Assessment Minimum

An alignment assessment should identify:

- which comparison object it governs
- which relation is being assessed
- the alignment degree
- the alignment scope
- the translation burden
- the evidence sufficiency posture
- the confidence level
- the review status

## Non-Goal

This rubric does not impose fake numeric precision on doctrinal comparison.
