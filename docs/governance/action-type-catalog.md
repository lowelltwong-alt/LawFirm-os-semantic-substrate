# Action Type Catalog

Action types are controlled, reusable governance actions. They are first-class
operational objects, not just prose conventions.

## Purpose

This catalog makes repository operations explicit, reviewable, and machine-usable.

## Core Rules

- action types should be reused rather than improvised ad hoc
- actions should name target surface, required checks, and reviewer posture
- lifecycle-changing actions should remain explicit
