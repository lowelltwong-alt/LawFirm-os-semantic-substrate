# Retrieval Feedback and Proposal Promotion Policy

Retrieval tuning should remain governed in the same way claims, assertions, and
graph partitions remain governed.

## Policy

- retrieval feedback should be captured as explicit sidecar records
- proposal promotion should cite the feedback record that triggered the change
- asserted-first retrieval defaults remain the baseline
- inferred material requires explicit opt-in
- quarantine material must not be promoted through retrieval convenience alone

## Purpose

This policy keeps semantic graph iteration additive, reviewable, and aligned to
the repository's trust-boundary posture.
