# Evidence Sufficiency Rubric

Evidence sufficiency expresses how strong the support base is for a governed
comparison judgment.

## Categories

- `direct_primary_text`
- `strong_curated_secondary`
- `mixed_support`
- `indirect_inference`
- `thin_support`

## Usage

This rubric should be attached to alignment assessments rather than hidden in
freeform prose. It is not a substitute for actual evidence or provenance.

## Rule

If evidence sufficiency is weak, confidence and review posture should not imply
stronger certainty than the support base warrants.
