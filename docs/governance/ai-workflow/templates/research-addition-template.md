# Research Addition Template

Use for staged research or source synthesis that must not become canon automatically.

## Route
- route: `research_addition`
- mode: Edit

## Required sections

- Source summary
- Source boundary and license posture
- Trust zone
- Files changed
- Why this stays staged
- Validation run
- Follow-up promotion path, if any

## Forbidden

- canonical promotion
- unsupported claims
- raw internal data
- copyrighted full-text ingestion without an approved route
