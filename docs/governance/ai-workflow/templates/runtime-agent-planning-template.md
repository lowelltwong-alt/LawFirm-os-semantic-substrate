# Runtime Agent Planning Template

Use for planning agent harness or runtime architecture without implementing runtime in this repository.

## Route
- route: `runtime_agent_planning`
- mode: Plan

## Required sections

- Runtime capability being planned
- Law Firm contracts consumed
- Boundary with runtime repo
- Policy, approval, audit, and rollback assumptions
- Non-goals
- Runtime follow-up repo or issue

## Forbidden

- executable runtime implementation in this repo
- live connectors
- raw transcripts or production audit store
- side-effecting automation
- direct mutation of canonical truth from runtime observations
