# Math Breakthrough Impact Template

Use for evaluating whether a claimed mathematical breakthrough is architecturally relevant to Law Firm and whether it warrants governed follow-up.

## Route
- route: `math_intelligence`
- mode: Plan/Edit

## Required sections

- Claimed breakthrough
- Source type and source status
- Proof-status assessment
- Replication, benchmark, or peer-review status
- Math-domain tags
- Architecturally relevant surface
- Immediate Law Firm impact
- Near-term actions
- Explicit non-goals
- Whether a later `adaptation-proposal` should be considered

## Recommendation notes

- `deep_research` means a scoped follow-up research task or prompt.
- `deep_research` is not verified truth.
- `deep_research` is not automatic canon change.
- `deep_research` is not automatic runtime implementation.

## Forbidden

- automatic truth promotion
- automatic runtime implementation
- unsupported production claims
- treating rumors or preprints as verified
- internet-sourced semantic rewrites without governed review
- autonomous self-modification framing
