# Math Intelligence Template

Use for governed-learning intake of frontier math topics, proof claims, benchmark claims, and architecturally relevant mathematical developments.

## Route
- route: `math_intelligence`
- mode: Plan/Edit

## Required sections

- Frontier math topic or claim
- Source type and source status
- Proof status
- Math-domain tags
- Project-surface impact tags
- Recommendation
- Governed-learning output type
- Evidence limits and uncertainty
- Follow-up artifact or no-op rationale

## Recommendation notes

- `deep_research` means a scoped follow-up research task or prompt.
- `deep_research` is not verified truth.
- `deep_research` is not automatic canon change.
- `deep_research` is not automatic runtime implementation.

## Governed-learning posture

Use this route as a governed-learning input surface for governed recursive improvement:

`candidate signal -> assessment -> recommendation -> adaptation-proposal recommendation if reviewed -> promotion-decision only through existing authority path`

## Forbidden

- automatic truth promotion
- automatic runtime implementation
- unsupported production claims
- treating rumors or preprints as verified
- internet-sourced semantic rewrites without governed review
- autonomous self-modification framing
