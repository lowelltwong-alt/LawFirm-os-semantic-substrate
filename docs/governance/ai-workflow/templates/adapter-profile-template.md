# Adapter Profile Template

Use for vendor, platform, source-system, or mapping profiles.

## Route
- route: `adapter_profile`
- mode: Edit

## Required sections

- Adapter or mapping changed
- Source system / vendor surface
- Authority boundary
- Official-doc/source basis
- Affected profiles or mappings
- Validation commands

## Forbidden

- treating adapter files as semantic authority
- adding live connector execution code
- storing credentials, secrets, tokens, or production records
- creating production ingestion or sync behavior
