# Exceptions Runtime Contract Template

Use for Law Firm-side contracts consumed by `exceptions-lake-runtime`.

## Route
- route: `exceptions_runtime_contract`
- mode: Plan/Edit

## Required sections

- Contract surface changed
- Runtime consumer affected
- Contract SHA / version expectation
- Backward compatibility notes
- Validation commands
- Runtime follow-up required

## Forbidden

- live connector implementation
- production event store changes
- runtime schema redefinition outside Law Firm authority
- raw production conversation or transcript storage
