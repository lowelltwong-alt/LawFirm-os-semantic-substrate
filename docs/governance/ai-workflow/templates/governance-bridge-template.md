# Governance Bridge Template

Use when staged research or findings are moved into governed documentation.

## Route
- route: `governance_bridge`
- mode: Plan/Edit

## Required sections

- Source basis
- Current authority surface touched
- Target governance file(s)
- Canonical boundary analysis
- What is promoted and what remains staged
- Validation run
- Routing impact
- Follow-up needed

## Forbidden

- direct canon mutation without authority
- unsupported claims
- runtime implementation
- raw runtime storage
