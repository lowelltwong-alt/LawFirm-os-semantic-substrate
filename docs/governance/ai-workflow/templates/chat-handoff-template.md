# Chat Handoff Template

Use when turning chat output into scoped repository work.

## Route
- route: `chat_handoff`
- mode: Plan/Edit

## Required sections

- Source conversation or pasted text summary
- What is being carried forward
- What is explicitly not being promoted
- Proposed target route for follow-up work
- Allowed paths
- Forbidden paths
- Validation or review needed

## Forbidden

- treating chat output as canonical authority
- unsupported claims
- raw internal records
- direct schema or governance promotion without a selected route
