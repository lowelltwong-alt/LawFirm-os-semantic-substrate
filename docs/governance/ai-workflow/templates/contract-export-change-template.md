# Contract Export Change Template

Use when changing contract export bundles or contract consumption maps used by runtime repositories.

## Route
- route: `contract_export_change`
- mode: Plan/Edit

## Required sections

- Contract surfaces included
- Runtime consumers affected
- Contract SHA or version expectations
- Breaking vs non-breaking change assessment
- Validation commands
- Follow-up runtime work

## Forbidden

- runtime implementation
- raw transcript storage
- production persistence
- redefining schema meaning outside authority surfaces
