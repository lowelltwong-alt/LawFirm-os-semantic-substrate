# Retrieval and Access Contract Template

Use for changes to retrieval, access-decision, answer-evidence, answer-event, or grounded-answer evaluation contracts.

## Route
- route: `retrieval_access_contract`
- mode: Plan/Edit

## Required sections

- Retrieval or access surface changed
- Affected schemas, examples, or governance docs
- Privilege / sensitivity impact
- Evidence and citation impact
- Validation commands
- Production claim impact

## Forbidden

- production retrieval quality claims without evidence
- raw client data
- bypassing access-decision contracts
- treating vectors, indexes, GraphRAG summaries, or answer caches as canonical truth
