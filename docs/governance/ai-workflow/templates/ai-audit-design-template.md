# AI Audit Design Template

Use for AI interaction audit capture, retention, privacy, sealed transcript, and audit-event design work.

## Route
- route: `ai_audit_design`
- mode: Plan/Edit

## Required sections

- Audit surface being changed
- Envelope fields affected
- Transcript boundary affected
- Retention and legal-hold impact
- Privacy and privilege impact
- Runtime implementation impact
- Validation or review required

## Forbidden

- raw production conversation content
- production audit lake implementation
- sealed transcript storage in this repo
- real user prompt or output examples
- runtime persistence changes without a runtime route
