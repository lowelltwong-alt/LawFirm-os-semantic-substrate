# Math Domain Map

Use these tags when routing or assessing math-intelligence items.

## Core domain tags

- `linear_algebra`
  - Vectors, matrices, decompositions, embeddings, and transforms relevant to representation and retrieval.
- `probability_statistics`
  - Uncertainty, distributions, estimation, and error characterization.
- `bayesian_inference`
  - Probabilistic updating, priors, posterior reasoning, and calibrated uncertainty.
- `optimization`
  - Objective tradeoffs, constrained search, convex and non-convex planning methods.
- `information_theory`
  - Compression, entropy, signal value, and channel or evidence efficiency.
- `graph_theory_spectral_graph_theory`
  - Connectivity, graph structure, spectral properties, and network reasoning.
- `logic_proof_theory`
  - Formal reasoning systems, proof objects, soundness, and verification.
- `model_theory`
  - Semantics of formal structures and interpretation across logical systems.
- `category_theory`
  - Structure-preserving mappings, compositionality, and interface abstraction.
- `topology_geometry`
  - Shape, continuity, manifolds, distance, and geometric structure.
- `dynamical_systems`
  - State evolution, stability, feedback, and temporal behavior.
- `control_theory`
  - Closed-loop control, robust planning, observability, and governance constraints.
- `game_theory`
  - Multi-agent incentives, equilibrium, competition, and adversarial strategy.
- `numerical_analysis`
  - Approximation, stability, convergence, and computational error.
- `measure_theory_analysis`
  - Rigorous foundations for integration, limits, continuity, and approximation.
- `complexity_theory`
  - Resource bounds, tractability, hardness, and feasibility claims.
- `cryptography`
  - Integrity, secrecy, proof systems, secure exchange, and trust boundaries.
- `causal_inference`
  - Intervention-aware reasoning, confounding, and causal structure assessment.

## Tagging rule

Apply one or more domain tags to every watch item, assessment, or roadmap candidate. Tags help route candidate signals into governed review; they do not prove theorem truth or implementation fitness.
