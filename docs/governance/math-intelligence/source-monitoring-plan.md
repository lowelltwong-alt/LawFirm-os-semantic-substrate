# Source Monitoring Plan

Internet use for this route is off by default. It is only allowed when verifying official source types or public source-monitoring references.

## Official source types

- formal journal publication pages
- official conference proceedings pages
- official institutional theorem or proof repository pages
- official proof-assistant project pages
- official benchmark host pages
- official lab or research group pages when identifying source type only

## Public monitoring references

- public preprint indexes
- public proceedings indexes
- public benchmark leaderboards
- public research digests or watchlists used only as monitoring references

## Monitoring rules

- Verify source type before treating an item as anything more than a candidate signal.
- Do not treat public appearance as truth confirmation.
- Do not treat preprints, rumors, or benchmark claims as verified theorem truth.
- Do not build a production feed or autonomous source-ingestion workflow from this plan.
- Record source status separately from proof status.

## Output posture

This plan supports watch items, summaries, impact assessments, deep-research prompts, prototype recommendations, and adaptation-proposal recommendations. It does not authorize direct canonical, schema, runtime, or production retrieval changes.
