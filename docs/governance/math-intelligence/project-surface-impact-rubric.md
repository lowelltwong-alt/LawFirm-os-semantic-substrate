# Project Surface Impact Rubric

Use this rubric to assess potential Law Firm relevance. Scores indicate review priority only, not correctness, readiness, or implementation approval.

## Rubric bands

- `low`
  - Weak or indirect relevance.
- `medium`
  - Plausible relevance with bounded follow-up value.
- `high`
  - Strong relevance to architectural, governance, or planning choices.

## Surface rubric

- `architecture`
  - Assess whether the item changes composition, abstraction, or systems structure assumptions.
- `ontology`
  - Assess whether the item changes how formal meaning or semantic organization should be reviewed.
- `retrieval`
  - Assess whether the item changes evidence access, grounding, or uncertainty handling assumptions.
- `agents`
  - Assess whether the item changes bounded planning, coordination, or reasoning expectations.
- `ai_interaction_audit_ledger`
  - Assess whether the item could change audit-event structure, verification logic, or integrity assumptions.
- `transcript_governance`
  - Assess whether the item could affect sealed transcript handling, review posture, or exposure boundaries.
- `retention_legal_hold_boundaries`
  - Assess whether the item could change retention logic, sealed-hold reasoning, or destruction constraints.
- `audit`
  - Assess whether the item changes traceability, reviewability, or evidence-chain expectations.
- `runtime_plans`
  - Assess whether the item changes what future runtime prototypes may be worth exploring.
- `exceptions_lake`
  - Assess whether the item changes governed-learning, exception aggregation, or pressure interpretation possibilities.
- `innovation_os`
  - Assess whether the item changes roadmap, adaptation, or planning priorities.

## Rubric reminder

High impact means the item deserves careful review, not direct implementation authority. Any concrete change still requires the existing governed authority path.
