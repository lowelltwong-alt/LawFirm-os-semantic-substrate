# Math Intelligence

This surface tracks frontier math developments as governed-learning inputs for governed recursive improvement across Law Firm architecture and planning surfaces.

## Purpose

Use this area to watch, assess, route, and summarize potentially relevant mathematical developments without treating public claims as verified truth and without granting direct change authority.

## Relation to the AI router

Tasks in this area should use the `math_intelligence` route in `docs/governance/ai-workflow/ai-task-route-table.yaml` and the templates in `docs/governance/ai-workflow/templates/math-intelligence-template.md` and `docs/governance/ai-workflow/templates/math-breakthrough-impact-template.md`.

## Governed-learning boundary

This is a governed-learning input surface for governed recursive improvement, not autonomous self-modification.

It may create or recommend:
- watch items
- proof or source reviews
- math impact assessments
- roadmap update candidates
- deep-research prompts
- prototype recommendations
- adaptation-proposal recommendations

It may not directly create:
- canonical ontology changes
- schema changes
- runtime changes
- production retrieval changes
- promotion decisions

Use the existing authority path:

`candidate signal -> assessment -> recommendation -> adaptation-proposal recommendation if reviewed -> promotion-decision only through existing authority path`

## Non-goals

- runtime implementation
- source-ingestion pipeline creation
- production monitoring feed design
- theorem-truth promotion from rumor or preprint alone
- autonomous repo rewriting
