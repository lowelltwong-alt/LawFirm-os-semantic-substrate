# Assertion Data Templates

This directory holds governed assertion templates and, later, governed
assertion objects.

## Default Position

- assertions are first-class governed objects
- asserted material belongs in the asserted partition unless policy says otherwise
- inferred, boundary, and quarantine material must remain structurally separate

## Retrieval Default

Prefer asserted content by default. Include inferred or boundary material only
through explicit retrieval policy. Exclude quarantine material unless a review
workflow opts in.
