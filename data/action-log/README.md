# Action Log Templates

This directory holds governed action log entries.

Action logs make operational changes traceable without flattening them into
generic comments or commit messages alone.

## Governance Review Cadence Artifact

Use `governance_review_cadence.template.yaml` to instantiate required monthly
and quarterly governance reviews.

Each instantiated review must include:

- drift report
- exception trend report
- promotion outcomes report

If any mandatory output is missing, governance readiness is not met.
