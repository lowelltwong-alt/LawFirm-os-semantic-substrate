# Comparison Data Templates

This directory holds comparison object templates and, later, governed
comparison objects.

Comparisons should remain explicit about scope, compared objects, evidence, and
graph posture rather than being implied indirectly.

Phase 4 adds a governed assessment layer above simple comparison labels.

That means comparison objects may now reference alignment assessments that make
scope, translation burden, evidence sufficiency, confidence, and review posture
machine-usable without flattening nuanced judgment into fake numeric precision.

Phase 5 adds operational governance around these comparison surfaces, including
action types, object sets, reviewer roles, and bounded pilot slices.
